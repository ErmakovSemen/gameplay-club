# ⚡ GAME PLAY — сайт и Telegram-бот

Лендинг игрового клуба **Game Play** (Электросталь) и Telegram-бот бронирования
мест на PHP + SQLite. Всё лежит в корне сайта, внешних зависимостей нет.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | Лендинг: зоны, цены, контакты. Один файл, картинки внутри (base64). |
| `core.php` | Ядро бота: база, цены, вместимость зон, обёртка над Telegram API. |
| `webhook.php` | Приём обновлений Telegram, все экраны и админка. |
| `reminder.php` | Напоминания за час до брони. Запускается по cron. |
| `set_webhook.php` | Разовая привязка бота к вебхуку. |
| `config.php` | **Секреты. В git не попадает.** Создаётся из `config.example.php`. |
| `.htaccess` | Закрывает от скачивания базу, ядро и конфиг. |
| `tests/test_bot.php` | 131 локальный тест логики бота (без обращений к сети). |

## Требования

- PHP **8.0+** (код использует `str_starts_with`), расширения `pdo_sqlite` и `curl`
- Apache с поддержкой `.htaccess` (на nginx правила нужно перенести в конфиг)
- HTTPS — Telegram принимает вебхук только по https

## Установка

```bash
# 1. Секреты
cp config.example.php config.php
# впиши BOT_TOKEN от @BotFather и свой Telegram id в ADMIN_IDS
# WH_SECRET и CRON_KEY сгенерируй так:
php -r "echo bin2hex(random_bytes(24)), PHP_EOL;"
```

> **WH_SECRET** может содержать только `A-Z a-z 0-9 _ -`.
> Кириллица или пробелы — и Telegram откажется ставить вебхук.

```bash
# 2. Привязка вебхука — один раз, в браузере:
#    https://ВАШ-ДОМЕН/set_webhook.php?key=CRON_KEY
#    После успешного ответа файл можно удалить с сервера.

# 3. Cron каждые 5 минут — напоминания:
*/5 * * * * php /путь/к/сайту/reminder.php
#    или по URL: curl -s "https://ВАШ-ДОМЕН/reminder.php?key=CRON_KEY"
```

База `gameplay.db` создастся сама при первом обращении. Каталог сайта должен быть
доступен веб-серверу на запись (SQLite пишет рядом с базой файлы `-wal` и `-shm`).

## Локальная разработка

```bash
php -S 127.0.0.1:8899 -t .
```

Тесты (сеть не используется, база — временная):

```bash
php tests/test_bot.php
```

Тесты проверяют в том числе, что **цены на сайте совпадают с ценами в боте** —
если меняешь прайс, правь его в обоих местах, иначе тесты упадут.

## Команды бота

| Команда | Кто | Что делает |
|---|---|---|
| `/start` | все | Главное меню |
| `/book` | все | Бронирование: зона → тариф → дата → время |
| `/load` | все | Загруженность сейчас и прогноз на 6 часов |
| `/prices` | все | Прайс по всем зонам |
| `/my` | все | Свои брони, отмена |
| `/admin` | админ | Брони по дням, сетка занятости, статистика, CSV-выгрузка |

## Безопасность

- `config.php` с токеном не в git и закрыт `.htaccess`
- `webhook.php` принимает только POST с заголовком `X-Telegram-Bot-Api-Secret-Token`
- `reminder.php` и `set_webhook.php` по URL требуют `?key=CRON_KEY`
- Данные из `callback_data` проверяются по справочникам зон, тарифов, дат и часов
- Проверка свободных мест и вставка брони идут одной транзакцией `BEGIN IMMEDIATE`,
  поэтому одновременные подтверждения не займут одно место дважды
- Имена пользователей экранируются перед вставкой в HTML-сообщения

**Если токен когда-либо попал в git, чат или скриншот — отзови его
(`/revoke` у @BotFather) и впиши новый в `config.php`.**

## Деплой на VPS

Порядок важен: `server_setup.sh` берёт конфиг из `nginx/gameplay.conf.template`,
который приезжает вместе с файлами.

```bash
# 0. один раз — ключ на сервер, чтобы дальше всё шло без пароля
ssh-copy-id -i ~/.ssh/gameplay_deploy.pub root@СЕРВЕР

# 1. с ноутбука: прогнать тесты и залить файлы
./deploy.sh                       # параметры берутся из .deploy.env
./deploy.sh root@СЕРВЕР:/var/www/gameplay   # или явно

# 2. на сервере: nginx + PHP-FPM + HTTPS + cron
ssh root@СЕРВЕР
cd /var/www/gameplay && bash server_setup.sh gameplaycc.ru
```

`deploy.sh` **не трогает** `config.php` и базу на сервере — секреты и брони
переживают любую перевыкладку.

### Apache или nginx

`.htaccess` работает только под Apache. Под nginx он игнорируется, и без
переноса правил `config.php` с токеном бота отдавался бы по прямой ссылке.
Правила перенесены в `nginx/gameplay.conf.template`; проверить их можно
локально, на настоящем nginx + PHP-FPM:

```bash
bash tests/test_nginx.sh
```
