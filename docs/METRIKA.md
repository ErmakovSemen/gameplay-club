# Яндекс.Метрика

Счётчик `113524983`: https://metrika.yandex.ru/settings?id=113524983

Один счётчик установлен в `index.html` и `booking/index.html`. Часовой пояс — Москва, валюта — RUB. Включены Вебвизор, карта кликов и отслеживание ссылок. Поля имени и телефона помечены `ym-disable-keys` для исключения их содержимого из записи Вебвизора.

## Цели

| Цель | Условие | ID |
|---|---|---|
| Успешное бронирование | Событие `booking_success` | 670645926 |
| Открытие страницы бронирования | URL содержит `gameplaycc.ru/booking/` | 670646095 |
| Клик по телефону | Все телефонные ссылки | 670646181 |

Событие `booking_success` отправляется после успешного ответа API с положительным ID брони. Ответ ловушки для ботов с ID 0 не учитывается. Передаются только ID брони, зона и тариф; имена, телефоны и доход не передаются. Сбой аналитики не прерывает подтверждение брони.

## Реклама

Рекламная подписка Яндекс Бизнеса №55935489: https://yandex.ru/business/subscription/campaign/55935489/tab-goals

После установки обновить проверку счётчика в разделе «Цели». Основной результат для оптимизации — успешная бронь, остальные цели вспомогательные. Не менять бюджет для подключения аналитики.

## Фактические оплаты

Бронь бесплатна, оплата происходит в клубе. Стоимость брони не является полученной выручкой. Передача фактических оплат пока не реализована: нужно определить систему учёта, сохранять ClientID Метрики вместе с бронью и импортировать оплаченные заказы с реальной суммой, временем оплаты и уникальным ID для дедупликации.

## Проверка

На главной и `/booking/` должен загружаться один счётчик. Проверить запросы и диагностические сообщения Метрики, затем поступление посещений в отчёты. Положительные и отрицательные ответы API проверяются локально без создания тестовой брони в рабочей базе. После согласованной реальной брони проверить достижение `booking_success` в Метрике.
